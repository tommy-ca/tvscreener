# v0.2.0 Roadmap: Advanced Strategy Layering & Gemini CLI Skills

Date: 2026-04-03
Status: DRAFT / RESCHEDULED

This roadmap defines the next major development cycle following the service-oriented refactor of the `tvscreener-ext` package.

## 1. Gemini CLI Skills (Automation)
The goal is to automate complex professional workflows via specialized Gemini CLI Skills.

- **`environment-validator` (Pilot)**:
    - Automate Zero-Fork compliance checks.
    - Verify Prefect server and worker health.
    - Check disk usage and artifact retention status.
- **`market-scanner`**:
    - Interactive guide for configuring scans (asset type, universe, mode).
    - Auto-generation of `PipelineRunSpec` JSON.
- **`lakehouse-auditor`**:
    - Natural language SQL interface for Iceberg tables.
    - Summary reports on data freshness and ingestion health.
- **`workflow-manager`**:
    - Command-line control for Prefect queues and deployments.
    - Automated pruning of late runs.
- **`strategy-developer`**:
    - Scaffolding for new `Field` and `Screener` subclasses.
    - Automated unit test generation for strategy logic.

## 2. Strategy Layering (Advanced Technicals)
Expand the edge analytics engine with professional-grade institutional concepts.

- **ICT/SMC Module**:
    - **Fair Value Gaps (FVG)**: Detection of price imbalances across multiple timeframes.
    - **Liquidity Sweeps**: Identification of stop-run levels and liquidity grabs.
    - **Market Structure Shift (MSS)**: Automated detection of trend reversals.
- **Volume Profile**:
    - Implementation of Point of Control (POC), Value Area High (VAH), and Value Area Low (VAL).
    - Support for Volume-at-Price distribution analysis.
- **Multi-Timeframe Confluence v2**:
    - Weighted alignment of ICT/SMC features with existing trend/momentum factors.

## 3. Data Infrastructure (Scalability)
Improve the medallion lakehouse to handle broader universes and higher-resolution data.

- **Tiered Namespaces**:
    - Migrate physical tables to logical tiered namespaces: `tvscreener.<asset>.<instrument>.<stage>.<dataset>`.
    - Implement automated schema evolution for new technical indicators.
- **Partitioned Snapshots**:
    - Add support for date-partitioned Parquet snapshots in the `ExportService`.
- **High-Resolution Bars**:
    - Implement `market_bars` (OHLCV) ingestion stage to support sub-hourly strategy detection.

## 4. Universe Refinement
- **Binance Momentum**: Finalize the `binance_spot_cs_momentum` universe with market-cap anchored anchors.
- **Stock Proxies**: Expand the `market_risk` basket to include global macro indices (Indices, Yields, Commodities).
